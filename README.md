## 📖 About The Project

Welcome to the **Eid Mubarak App** repository! This project is designed to spread joy and festive greetings during Eid. It leverages the latest web technologies to deliver a smooth, interactive, and visually stunning user experience.

### ✨ Key Features

- **Modern UI:** Built with **Tailwind CSS v4** for clean, responsive, and highly customizable designs.
- **Smooth Animations:** Powered by **Framer Motion** for delightful micro-interactions and page transitions.
- **High Performance:** Utilizing **Next.js 16** (App Router) with React 19 for optimal speed and SEO.
- **Fully Responsive:** Looks perfect on mobile, tablet, and desktop screens.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v20 or newer recommended) and npm/yarn/pnpm installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/eid-mubarak.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd eid-mubarak
   ```

3. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

5. **Open your browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view the application.

## 📝 Guidance & Best Practices

If you are developing or maintaining this project, please consider the following guidelines:

- **Components:** Keep components small, modular, and reusable. Create a `components/` directory inside `app/` or at the root if needed.
- **Animations:** Use Framer Motion thoughtfully. Avoid overwhelming the user with too many simultaneous animations. Use `layoutId` for smooth transitions between different UI states.
- **Styling:** Utilize Tailwind's utility classes. Extend the theme in `tailwind.config.ts` (or equivalent postcss configuration) if you need custom design tokens (colors, fonts).
- **Code Quality:** Run `npm run lint` before committing to ensure the codebase remains clean and consistent.
